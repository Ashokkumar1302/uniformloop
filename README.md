# UniformLoop

UniformLoop is a small community marketplace prototype for passing school uniforms, textbooks, sportswear, and supplies to another family.

## Run it

Open `index.html` in a browser. The app uses plain HTML, CSS, and JavaScript, so no install or server is required.

## What works

- Browse demo listings and search by item, school, or area.
- Rank matches by school and grade, with an optional sample size preference; search or filter by item type.
- See match scores based on the selected school, grade, and size preferences.
- Open a listing, save it to a shortlist for the current session, and record an item request.
- Add a listing with school, grade, size, condition, and free/swap/for-sale terms.
- Keep added listings and requests in browser local storage.
- Switch to My listings and see the impact snapshot.

## Prototype notes

The names, listings, and community totals are sample demo data. This prototype has no accounts, chat, payments, QR scanning, or backend. Listing and request changes are stored only in the current browser. Contact details and exact addresses are intentionally not collected.
